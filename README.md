# Каталог персонажей «Игры престолов»

Учебное кроссплатформенное приложение на Flutter, выполненное для лабораторной работы № 2.

Приложение показывает каталог персонажей вселенной «Игры престолов». В этой версии используются локальные тестовые данные из 20 записей. Подключение к сетевому источнику предусмотрено в следующей лабораторной работе.

## Возможности

- просмотр списка персонажей;
- поиск персонажа по имени;
- отображение сообщения, если по запросу ничего не найдено;
- просмотр подробной информации о персонаже;
- переход к отцу персонажа, если он указан в данных;
- возврат к списку с сохранением поискового запроса и позиции прокрутки;
- переключение светлой и тёмной темы;
- переключение русского и английского языка;
- работа при обычной и узкой ширине окна.

## Использованные технологии

- Flutter и Dart;
- `flutter_bloc` для управления состоянием;
- `go_router` для переходов между экранами;
- ARB-файлы для локализации интерфейса;
- Material 3 для оформления приложения.

## Структура проекта

Код каталога расположен в `lib/features/character` и разделён на три части:

- `data` — локальные данные и реализация репозитория;
- `domain` — модель персонажа и интерфейс репозитория;
- `presentation` — состояния, Cubit и экраны приложения.

Cubit и состояния находятся в `presentation/bloc`, а виджеты экранов — в
`presentation/view`.

Общие компоненты находятся в `lib/common`:

- `navigation` — маршруты приложения;
- `theme` — светлая и тёмная темы;
- `locale` — переключение языка;
- `widgets` — общие элементы интерфейса.

## Запуск проекта

Перед первым запуском необходимо установить зависимости:

```shell
flutter pub get
```

Запуск в браузере:

```shell
flutter run -d chrome
```

Запуск приложения для Windows:

```shell
flutter run -d windows
```

По умолчанию используется русский язык. Чтобы сразу запустить приложение на английском языке:

```shell
flutter run -d chrome --dart-define=LOCALE=en
```
